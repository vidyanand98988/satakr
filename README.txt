SATARK website, offline copy

1. Unzip this folder anywhere and keep the folders together.
2. Open index.html in Chrome or Edge (double-click it, or drag it into the browser).
3. Click Present (top right) for full screen. Use the right and left arrow keys,
   or a presentation clicker, to move between chapters.

The 3D scenes, fonts, photos, letters and videos are all inside this folder,
so it works without internet.

Two things need internet:
- The contact form on contact.html sends straight to the team inbox through
  Formspree (form ID mdeeaaro).
  To use a different Formspree form, change the action="..." on the form
  with id="demoForm" in contact.html. If sending fails, the page shows the
  message ready to copy or open in a mail app instead.
- Links to Marginal Revolution, The Better India, DailyGood and the original
  mandate PDF on Google Drive open those sites.

To put it online, upload the whole folder to any static host (Netlify,
GitHub Pages, Cloudflare Pages). index.html is the home page.
